🔐 SEGURANÇA IMPLEMENTADA

✅ Row Level Security (RLS)
   - Leitura pública: products, kits, categories, testimonials
   - Leitura privada: customers, orders, favorites
   - Escrita: service_role apenas

✅ Storage Security
   - Buckets públicos para leitura (URLs acessíveis)
   - Upload restrito ao service_role (backend)
   - Delete restrito ao service_role (backend)

✅ Autenticação
   - Supabase Auth
   - Variáveis de ambiente separadas (anon vs service_role)
   - Sem exposição de keys sensíveis
